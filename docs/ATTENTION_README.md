# L'attention de la FPS : le fil, dans l'ordre

*29/09/2026. Onze notes écrites en une semaine, chacune dans l'élan du moment. Ce fil dit dans
quel ordre les lire, ce que chacune demande et répond, et ce qui est dans le pipeline aujourd'hui.
Les notes n'ont pas été réécrites après coup : quand une phrase y est devenue fausse depuis, elle
est marquée sur place (date entre parenthèses). Point de départ : la feuille de route
`FEUILLE_DE_ROUTE_attention_flow.md` (18/09), qui posait la considération comme direction.*

## La méthode, en quatre règles

Petits pas ; observer avant de croire (un banc, deux seeds, un témoin) ; jamais mille règles (une
modulation multiplie, elle n'ajoute pas ; une constante à la fois ; le même principe partout plutôt
qu'une exception) ; tout réversible (un interrupteur, éteint par défaut, jusqu'à décision).

## Ce qui est dans le pipeline, en une phrase chacun

- **Saillance** s = c·[ν + (1 − ν)·m] : le contexte c désigne (l'entrée relative à sa médiane),
  la nouveauté ν module, la valeur m ramène le familier chéri.
- **Attachement** : pour chaque strate dans le contexte qui reste, m suit le bien-être du soi
  (mode `soulagement` : le mieux compte plus que le niveau) ; la signature suit l'état du monde.
- **Silence** : surprise du chœur sous son habituel, et rien dans l'entrée qui reste.
- **Rappel** : en silence, le lieu chéri que le présent appelle (ressemblance × m), sinon le plus
  chéri ; le monde reprend la main dès qu'il parle ; la porte repose un souvenir qui fait mal, sans
  le dévaluer.
- **Rêve** (éteint) : en silence, le tour de tous les lieux chéris, monde et soi, puis du substrat,
  par bribes d'une demi-respiration du système au plus (un lieu à soi qui n'est pas là cède son tour après un lissage ; un
  souvenir du monde garde son temps plein) ; un lieu visité est vécu strate par strate à la mesure de
  son degré de soi ; ce que seul le monde a vécu n'est pas réécrit par le rêve.
